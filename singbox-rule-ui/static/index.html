SOCKS5

Enable a SOCKS5 inbound for LAN clients. Set port 0 to disable.

2022-blake3 encryption requires the gateway and server clocks to be within 30 seconds, otherwise the node connects but transfers 0 B/s. Keep NTP running on this host.

Shadowsocks fill-in guide: method 2022-blake3-aes-256-gcm requires a 44-char base64 key from `ssservice genkey` (not a plain password). For Caddy/WebSocket disguise: plugin=v2ray-plugin, plugin_opts=mode=websocket;tls;host=YOUR_DOMAIN;path=/YOUR_PATH — both fields are required, leaving them empty removes the disguise and the node breaks.

SOCKS5 local relay: point to a local socks5 entry (sslocal/ss-local/Dante) on 127.0.0.1, e.g. server=127.0.0.1 port=10010. No password/encryption needed. Typical use: shadowsocks + SIP003 plugin in sing-box intermittently stalls (0-13MB/s, downloads cut off); running the official sslocal client locally and routing sing-box through it restores full speed.
